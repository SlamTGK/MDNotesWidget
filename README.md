# MD Notes Widget

Android-приложение для локальных Markdown-заметок и виджетов рабочего стола. **Android 12+ · Kotlin · версия 3.3.0**

[English](README_en.md) · [Скачать APK](https://github.com/SlamTGK/MDNotesWidget/releases/latest)

## Возможности

- Два виджета: компактный и расширенный. Случайные заметки, закрепление, создание и ручное обновление.
- **Общие настройки приложения и виджета:** папка, теги, тема, шрифт, интервал и тихие часы. Открываются из приложения или нажатием заголовка виджета. Изменения сохраняются только кнопкой **«Применить»**. Настройки существующего виджета переносятся автоматически.
- Просмотр Markdown: заголовки, списки, таблицы, зачёркивание, блоки кода, чекбоксы и ссылки. Локальные изображения показываются отдельной лентой превью.
- Ссылки `[[заметка]]`, `[[путь/заметка|подпись]]` и относительные Markdown-ссылки. При неоднозначном имени приложение не открывает случайный файл.
- **Редактор с автосохранением** после паузы ввода, локальным черновиком и проверкой внешних изменений. Во время редактирования свайп отключён. Ошибка записи не считается успешным сохранением; пустой текст тоже сохраняется.
- Поиск по имени и всему содержимому с отменой предыдущего запроса; избранное и история последних 50 открытых заметок.
- Фильтры тегов из YAML frontmatter и `#хэштегов`: И/ИЛИ, исключаемые теги, вложенные теги и только избранное. Фильтр `work` включает `work/project`, но не `workshop`.
- Выбор тегов и исключённых папок из списков с поиском, флажками и количеством заметок. Исключение по пути включает подпапки; прежние исключения по имени сохраняют своё действие. Список подходящих заметок доступен до применения.
- Папки с точкой в начале имени автоматически исключаются на любой глубине и не показываются в выборе папок. Счётчик отдельно показывает число заметок после исключения папок и число совпадений по остальным фильтрам.
- **Корзина приложения:** копия заметки сохраняется перед удалением исходного файла. В меню просмотрщика выберите «Восстановить из корзины». Восстановление идёт в корень выбранной папки; существующий одноимённый файл не перезаписывается.
- Ежедневные заметки с именем `YYYY-MM-DD`, подпапка для новых заметок и шаблон с `{{date}}` / `{{title}}`.
- «В этот день»: только прошлые годы, без фильтров тегов, избранного и пользовательских исключений папок. Приоритет даты: YAML `created`, затем `date`, затем YYYY-MM-DD в имени. Дата изменения не используется; заметки без даты пропускаются. Служебные папки исключаются всегда.
- Свои цвета, включая прозрачность `#AARRGGBB`, и предпросмотр текущей темы и шрифта.

## Начало работы

1. Установите APK из Releases.
2. Добавьте виджет на рабочий стол и выберите папку через системный диалог Android.
3. Дождитесь сканирования, настройте подборку и нажмите **«Применить»**. Для редактирования нужен доступ на запись; папки только для чтения можно просматривать.
4. При использовании Obsidian выберите **корень vault** и при необходимости укажите его имя. Поддерживаются хранилища во вложенных папках.

При изменении состава файлов вне приложения нажмите «Пересканировать файлы». Периодическое обновление также пересканирует дерево; индекс тегов перечитывает изменившиеся файлы. Если провайдер не сообщает дату изменения, содержимое проверяется заново.

## Важные особенности

- Фоновая работа выполняется через **WorkManager**: интервалы от 15 минут, время приблизительное. Android может отложить обновление в Doze или при ограничениях батареи. Тихие часы относятся к автоматическому обновлению, ручное доступно всегда.
- **Xiaomi / HyperOS:** для фоновой работы может потребоваться разрешить автозапуск и снять ограничения батареи.
- Виджеты показывают текстовое **превью** (до 2000/4000 символов); полный текст открывается в просмотрщике. Расширенный виджет не является прокручиваемым редактором.
- Автосохранение записывает файл. «Отменить несохранённые правки» удаляет черновик и перечитывает последнюю сохранённую версию, а не отменяет уже выполненные автосохранения.
- При конфликте с Obsidian/Syncthing черновик сохраняется отдельно, исходный файл не перезаписывается. Скопируйте нужные правки перед удалением конфликтующего черновика. SAF не предоставляет универсальной транзакционной записи между разными приложениями.
- Корзина и черновики находятся в данных приложения. Очистка данных/удаление приложения удалит эти локальные копии. Корзина не заменяет резервное копирование хранилища.
- YAML поддерживается в распространённых формах: `tags: [one, two]`, `tags: one`, список `- tag`. Сложные YAML-конструкции и все расширения Obsidian не поддерживаются. Теги из блоков кода не учитываются.

## Сборка и проверки

Нужны **JDK 17**, Android SDK Platform 36 и Build Tools 36.0.0. Укажите `ANDROID_HOME` либо `sdk.dir` в локальном `local.properties`.

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Windows:

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

Gradle 8.11.1 закреплён в Wrapper; дистрибутив проверяется по SHA-256. Debug APK: `app/build/outputs/apk/debug/app-debug.apk`.

Для подписанной release-сборки задайте `KEYSTORE_PATH`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`, затем выполните `./gradlew assembleRelease`. Подмены release-ключа debug-ключом нет.

### CI и публикация

Push/PR запускают unit-тесты, Android Lint и сборку debug APK. Тег `v*` после успешных проверок запускает release-сборку и публикацию в GitHub Releases. Секреты репозитория: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.

### Архитектура

- `EditorViewModel` — сессия редактирования и очередь сохранения.
- `NoteRepository` — запись, проверка конфликтов, черновики и корзина.
- `MarkdownFileScanner`, `NoteMetadata`, `TagIndexManager` — SAF-сканирование, метаданные и инкрементальный индекс.
- `WidgetUpdateCoordinator`, `WidgetUpdateWorker` — независимые фоновые задачи каждого виджета.
- `AtomicJsonStore` — атомарная запись локальных JSON; операции изменения списков сериализованы.
- Markwon — рендер Markdown; Material 3 — интерфейс.

Регрессионные unit-тесты находятся в `app/src/test/`: метаданные, фильтры, миграция общих настроек, черновик настроек и атомарное хранилище. Перед релизом также проверьте на устройстве: поворот и сворачивание редактора и настроек, отозванный SAF-доступ, read-only провайдер, оба размера виджета, перезагрузку, Doze и восстановление из корзины.
